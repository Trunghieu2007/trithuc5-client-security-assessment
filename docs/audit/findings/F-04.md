# F-04: Exam answers are recoverable from a bundle-seeded client vault

**Severity:** Low  
**CVSS v4.0:** not scored — see `../03-methodology.md`.  
**Confidence:** Confirmed  
**Status:** Open  
**Evidence state:** LOCAL_CONFIRMED  
**Build pin:** V4.8.6, SHA-256 `ffe94aea9b327853b0b8836bf0d52e1f509fcc68c007bead7b8a888604389185`

## 1. Overview

This finding was verified against the source-hash-pinned V4.8.6 client build. Evidence comes from captured headers, static source review, or real extracted functions executed in an isolated Node VM with synthetic fixtures. No production state was modified.

## 2. Severity

**Assigned severity:** Low. **CVSS vector/score:** not scored. Attack prerequisites, complexity, privileges, user interaction, scope and impact are stated qualitatively below rather than converted into an uncalculated numeric score.

- Attack prerequisites: local script execution on the app origin or access to the pinned public bundle; no server credentials.
- Attack complexity: low for the measured paths; the functions execute offline from bundle literals or local state.
- Required privileges: none in the tested client context.
- User interaction: the tester performs the action in their own browser; no victim interaction was tested.
- Scope: browser-local by default; cross-client effects are UNVERIFIED.
- Confidentiality / integrity / availability: see Impact below; no availability impact was measured.

## 3. Status

Confirmed — Open. Evidence state: LOCAL_CONFIRMED.

## 4. Affected components

- gzip/XOR exam vault `var __ENC_GZ` (line 1464)
- bundle-literal chunk seeds (1496)
- claim token (1968)
- client-side grading

## 5. Security boundary

Answer keys and grading belong on a server if exam results have any consequence.

## 6. Root cause

The vault's claim token and PRNG seeds are in the same bundle as the encrypted data. The isolated decoder recovered 15 exams and 330 answer entries offline.

## 7. Evidence

- `F-04-T01` decodes the current vault and reports 15 exams / 330 answers.
- `poc_f04_exam_answers.js` is read-only and validated by `poc-suite-validation.txt`.

All evidence files are sanitized and indexed in `../evidence/README.md`. No real credential, real user record or production packet body is stored.

## 8. Reproduction prerequisites

- Pinned V4.8.6 source.
- Local Node decoder; no live exam attempt.

## 9. Reproduction steps

1. Locate the embedded compressed chunks and seed values.
2. Reconstruct the vault offline with the bundle's own algorithm.
3. Count exams and answer entries.

## 11. Expected behavior

Answer keys should not be present in client-downloadable artifacts; grading should occur server-side.

## 12. Actual behavior

The full answer set is recoverable offline from the shipped bundle.

## 13. Impact

Students can obtain answers before attempting exams. Because grading is client-side, scores are also user-controlled (see F-06 and F-03 context).

## 14. Attack scenario

A user copies the bundle, runs the documented decoder, and extracts the answer key without starting an exam.

## 15. Remediation

1. Remove answer keys and vault seeds from the client payload.
2. Grade on a server and return only the result.
3. Rotate any exam data that was previously exposed.
